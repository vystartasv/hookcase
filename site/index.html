02

THE WORKBENCH

Describe. Sign. Check. Diff.

Hookcase owns the narrow boundary where webhook integrations disagree: body bytes, timestamp, headers, and HMAC.

  1. CREATERead the event and one explicitly named env var.
  2. CHECKValidate fixture shape and recompute the signature.
  3. DIFFShow deterministic field changes and body hashes.
03

SAFETY RAILS

A fixture, not a delivery system.

Inputs are parsed and bounded before signing. The CLI makes no network calls, opens no receiver, and never replays a request.

Included

  • POST + JSON only
  • Canonical body and sorted headers
  • HMAC-SHA256 from an env-only secret
  • Stable exit codes and redacted output

Not included

No tunnel, receiver, network, proxy, replay, provider dialect, or secret store.

04

QUICKSTART

Create a checked receipt.

The placeholder below is intentionally not a credential, signature, or body hash.

bun install --frozen-lockfile
export HOOKCASE_SECRET='replace-me-locally'
bun run src/cli.ts create examples/event.json \
  --secret-env HOOKCASE_SECRET --out /tmp/hookcase-fixture.json
bun run src/cli.ts check /tmp/hookcase-fixture.json
bun run src/cli.ts diff /tmp/hookcase-fixture.json /tmp/hookcase-fixture.json
